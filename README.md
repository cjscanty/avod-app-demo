# AVOD — African Village of Discovery (Demo Build)

Interactive single-file demo of the multi-tenant homeschool platform for review & testing — sample data only, read-only.

## Open the app

Enable **GitHub Pages** (Settings → Pages → Source: main / root) to serve `index.html` at:

  https://cjscanty.github.io/avod-app-demo/

Or drop `index.html` into https://app.netlify.com/drop for an instant URL.

## What's inside

Two fully isolated villages — switch with the tenant picker in the sidebar:

- **Kingdom Preparatory** (gold crown, kingdomprep.org) — 3 courses, 6 learners, 14 lessons
- **Ubuntu Leadership Academy** (terracotta globe, ubuntu.avodlearning.org)

Sections: Village Square dashboard, My Journey portal with completion rings and printable weekly summary cards, Course Studio, Learners, Gradebook, Village Voice community, Branding, and the Chronicle audit log.

## Deep links

- `?village=cls_ula` — open Ubuntu Leadership Academy directly
- `?village=cls_kp&journey=tamika` — land on Tamika's parent journey page
